# 엑셀에서 푸른약국 앱으로 전환하는 날

1. **엑셀 입력 멈추기**: 이 시점부터 제약회사 장부·외상 장부 엑셀에는 더 입력하지 않는다. 이후 모든 입력은 앱에서 한다.
2. **파일 받기** (구글 드라이브)
   - `푸른약국 제약회사 장부.xlsx`: 드라이브에서 다운로드(.xlsx)
   - `외상 장부`(구글 시트): 파일 > 다운로드 > Microsoft Excel(.xlsx)
3. **백업 받기**: 앱 설정 > "백업 파일 받기" (지금까지 시험 데이터 백업. 안 받아도 지우기 직전에 서버가 자동 백업을 만든다)
4. **가져오기**: 앱 설정 > "엑셀에서 가져오기"
   1. 두 파일을 함께 선택하고 "미리보기"
   2. 표에서 거래처별 "계산 잔고"와 "엑셀 잔고"가 모두 "일치"인지 확인 (다르면 알려 주기)
   3. "기존 장부를 모두 지우고 처음부터 다시 가져오기"를 체크하고, 비밀번호와 `초기화`를 입력
   4. "모두 지우고 가져오기"를 누른다. 오류가 나면 아무것도 바뀌지 않는다.
5. **확인**
   - 제약회사 장부: 제약회사 목록의 잔고가 엑셀 시트 마지막 잔고와 같은지
   - 병원 외상: 한사랑의원 잔고, 단가표
   - 환자 외상: 미완불 건수와 합계
   - 결제 대상: 이번 달 금액이 평소 계산과 비슷한지
6. **회전 개월 수 설정**: 6개월이 아닌 제약회사는 제약회사 장부 위쪽 "결제 회전 [ ] 개월"에서 바꾼다. (비우고 다시 가져와도 한 번 정한 값은 남는다)
7. **엑셀 파일은 보관만**: 지우지 말고 읽기 전용으로 두고, 앱의 "백업 파일 받기"를 주기적으로 받아 둔다.

## 되돌리기
- 서버 안에는 지우기 직전의 백업이 `backups/before-reset-날짜.db`로 남는다. 필요하면 알려 주면 복구한다.
