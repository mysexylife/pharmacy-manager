# 푸른약국 장부

제약회사 장부, 병원 외상 장부, 환자 외상 장부를 폰과 PC에서 함께 쓰는 웹앱입니다.

## 권한

| | 약사 | 직원 |
|---|---|---|
| 환자 외상 장부 (입력, 메모장·완불 체크) | O | O |
| 병원 외상 장부 (입력, 조회) | O | O |
| 제약회사 장부 | O | 보이지 않음 (서버가 차단) |
| 삭제, 직원 계정 관리 | O | X |

- 폰에서는 장부가 기본으로 **최근 1년**만 표시되고, "전체" 버튼으로 전체를 볼 수 있습니다. 1년 이전 내역은 "이전 잔액"으로 합쳐 보여 주므로 잔고는 항상 정확합니다.
- 모든 입력·삭제·로그인은 `audit_log` 테이블에 기록됩니다.

## 약국 PC에서 시작하기 (Windows)

1. [Node.js](https://nodejs.org) LTS(22 이상)를 설치합니다.
2. 이 저장소를 ZIP으로 내려받아 압축을 풉니다. (GitHub의 Code → Download ZIP)
3. `start.bat`을 더블클릭하고, 브라우저에서 <http://localhost:3000> 을 엽니다.
4. 처음 한 번 약사 계정을 만들고, "직원 관리" 탭에서 직원 계정을 추가합니다.

데이터는 `data/pharmacy.db` 파일 하나에 저장됩니다. **이 파일이 장부 전체이므로 주기적으로 USB나 구글 드라이브에 복사해 백업하세요.** 환자 정보가 들어 있어서 저장소에는 올라가지 않습니다(`.gitignore`).

## 직원 폰에서 쓰기

- 약국 Wi-Fi 안에서만: `start-wifi.bat`으로 시작하고, 폰에서 `http://약국PC의IP:3000` 으로 접속합니다. 이 방식은 암호화(HTTPS)가 없으니 약국 내부망에서만 쓰세요.
- 약국 밖에서도 쓰려면 HTTPS가 필요합니다. 이때는 관리형 서비스로 옮기는 것을 권장합니다.

## 개발

```bash
npm test     # 권한·잔고 계산 테스트
npm start    # http://127.0.0.1:3000
```

환경 변수: `PORT`(3000), `HOST`(127.0.0.1), `DB_PATH`(data/pharmacy.db), `SECURE_COOKIE=1`(HTTPS 뒤에서 사용 시).
