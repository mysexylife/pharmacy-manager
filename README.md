# 푸른약국 장부

제약회사 장부, 병원 외상 장부, 환자 외상 장부를 폰과 PC에서 함께 쓰는 웹앱입니다.
요구사항은 [요구사항 정리 문서](https://claude.ai/artifact/SGY5m7tpAoWXLz8gmaGHSN)를 기준으로 만들었습니다.

## 기능

| 화면 | 내용 |
|---|---|
| 결제 대상 | 이번 달 결제 금액 = 6개월 전 월말 잔고 − 그 이후 결제액 − 그 이후 반품액. 제약회사별로 금액만 보이고 눌러야 계산 근거가 펼쳐집니다. 실제 결제액을 입력하면 장부에 결제로 기록됩니다. 처리 중인 반품과 반환 안 된 차용이 맨 위에 모입니다. |
| 제약회사 장부 | 입고·결제·조정 기록, 최근 6개월만 표시(이전 내역은 "이전 잔액" 한 줄), 반품 칸(처리 완료 체크 → 체크한 날짜로 장부에 반영, 풀면 빠짐), 차용 칸, 확인 메모, 차량번호 메모 |
| 병원 외상 | 처방조제약(원래 금액 − 할인액 5,000원), 일반의약품(병원 단가표 × 수량), 결제, 조정. 최근 한 달만 표시하고 달 단위로 더 불러옵니다. |
| 환자 외상 | 환자별 합계, 연체(30일 이상) 맨 위 표시, 연락처를 누르면 전화, "메모장 작성"·"완불" 체크 |
| 설정 | 연체 기준·할인액, 백업 파일, 엑셀(CSV) 내보내기, 비밀번호 변경, 휴지통(30일) |

- 계정은 약사 아이디 하나입니다. 어느 기기에서든 로그인하면 되고, "로그인 유지"를 고른 기기는 90일 동안 유지됩니다.
- 날짜는 `26.10.31`, `2026-10-31`, `10/31`, `10월 31일` 등 어떻게 써도 같은 날짜로 읽고 `26.10.31` 형식으로 보여 줍니다. 연도를 생략하면 올해로 봅니다.
- 삭제한 내역은 휴지통에 30일 보관됩니다.

## 내 컴퓨터에서 실행

[Node.js](https://nodejs.org) 22.5 이상이 필요합니다. 별도 패키지 설치는 없습니다.

```bash
npm start
```

<http://localhost:3000> 을 열고, 처음 한 번 약사 계정(비밀번호 10자 이상)을 만듭니다. 데이터는 `data/pharmacy.db` 한 파일에 저장됩니다. 윈도우에서는 `start.bat`을 더블클릭해도 됩니다.

## 서버에 올리기

이 앱은 Node 서버 + SQLite 파일 하나입니다. 어느 호스팅에든 올릴 수 있습니다.

- `Dockerfile`이 있습니다. 컨테이너를 돌릴 수 있는 서비스(Fly.io, Render, Railway 등)에 올리고, **`/data`에 영구 저장소(볼륨)를 연결하세요.** 연결하지 않으면 서버를 다시 시작할 때 장부가 사라집니다.
- 환경 변수: `PORT`(3000), `HOST`(기본 127.0.0.1, 서버에서는 0.0.0.0), `DB_PATH`(data/pharmacy.db), `SECURE_COOKIE=1`(HTTPS일 때), `TRUST_PROXY=1`(프록시 뒤에서 접속자 주소를 읽을 때).
- 반드시 HTTPS로 서비스하세요. 환자 이름·주민번호 앞자리·연락처가 오갑니다.
- 호스팅 서비스의 가격과 정책은 이 저장소에서 확인하지 않았습니다. 고르기 전에 직접 확인하세요.

## 백업

설정 → "백업 파일 받기"로 전체 데이터를 받을 수 있습니다. 환자 정보가 들어 있으니 안전한 곳에 보관하세요. 서버 쪽 자동 백업은 호스팅 서비스 기능에 따라 달라집니다.

## 아직 없는 것

- 기존 엑셀·구글 시트 데이터 가져오기 (실제 파일로 검증하며 따로 만들 예정)
- 입고·결제 기록의 화면 수정(지금은 삭제 후 다시 입력, API는 있음)과 병원 외상 기록 수정
- 이번 달 결제 금액 계산은 요구사항의 식을 그대로 구현했습니다. 실제 장부와 맞는지 한 달치로 대조해 보세요.
